
# Working Agreements

How The Dynamic 4 communicates and works together on Traffix.

## Communication Norms

### Channels (Where Decisions Live)

Quick questions and coordination happen in our group chat. Any decision that affects the project gets written down in a GitHub issue, PR, or the wiki, so nothing important lives only in chat.

### Response Times

- We reply to messages within **24 hours on weekdays** and within **36 hours on weekends**.
- PR review requests get a response within **24 hours**.
- If you can't review in time, say so and suggest someone else.
- On deadline days, responses to urgent requests should be provided within **4 hours**.

### Meeting Etiquette

- Every meeting has a short agenda posted beforehand and starts on time.
- One person speaks at a time.
- Everyone gets a turn before decisions are made.
- The scribe posts notes and action items within a day.

### PR Tone

- Review comments are about the code or documentation, not the person.
- Suggest a fix instead of only pointing out a problem.
- Phrase feedback as a question or suggestion (e.g., "What if we...?").
- Approve with at least one specific comment.
